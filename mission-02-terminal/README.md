# Mission 2 — Terminal

Practice using a command-line terminal and understand common commands.

## Topics to cover

- [ ] Print the current working directory: `pwd`.
- [ ] List files: `ls` (or `dir` on Windows Command Prompt).
- [ ] Change directories: `cd`.
- [ ] Create directories: `mkdir`.
- [ ] Create, copy, move, and remove files safely.
- [ ] Read command help and understand paths.
