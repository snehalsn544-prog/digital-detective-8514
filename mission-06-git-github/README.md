# Mission 6 — Git and GitHub

Learn how version control tracks changes and how GitHub hosts repositories.

## Topics to cover

- [ ] Explain repositories, commits, and branches.
- [ ] Check Git configuration and version.
- [ ] Practice `git status`, `git add`, and `git commit`.
- [ ] Connect a local repository to a GitHub remote.
- [ ] Push and pull changes.
- [ ] Explain what a pull request is and when it is used.

## Useful commands

```bash
git status
git add README.md
git commit -m "Update mission notes"
git log --oneline
git remote -v
git push
```

## Reflection

How does committing work in small, meaningful steps help a project?
