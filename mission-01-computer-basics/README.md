# Mission 1 — Know Your Computer

**Mission objective:** Explain how a computer receives input, processes information, produces output, and stores results. Identify hardware, software, and computer-based systems.

## Task 1.1 — Trace one activity using IPOS

**Chosen activity: Typing and saving a document**

| Stage | What happens in this example? | Possible hardware / component |
|---|---|---|
| Input | I press keys to type words and use the mouse or touchpad to select options. | Keyboard and mouse / touchpad |
| Processing | The word-processing application receives the keystrokes, displays the text, and processes actions such as spelling checks and formatting. The CPU performs the instructions and RAM holds the work temporarily while the application is running. | CPU / processor and RAM |
| Output | The typed document appears on the screen. | Monitor / screen |
| Storage | When I press Save, the document is written to a file on the SSD or hard drive. If I choose an online drive, it can also be stored in cloud storage. | SSD, hard drive, or cloud storage |

**How the activity moves from input to output and storage:** The keyboard sends the characters to the computer. The CPU processes the instructions while the application uses memory. The screen shows the words as output. When Save is selected, the application stores the document as a file so it can be opened later.

## Task 1.2 — Identify hardware and software

Hardware is the physical part of a computer that can be touched. Software is a set of programs that tells the computer what to do.

| Item / software name | Hardware or software? | Software type (if applicable) | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands |
| Mouse | Hardware | Not applicable | Used to point, click, and select items |
| Monitor | Hardware | Not applicable | Displays text, pictures, and other output |
| RAM | Hardware | Not applicable | Temporarily holds data and programs currently in use |
| SSD | Hardware | Not applicable | Stores files and applications for later use |
| Windows 11 | Software | Operating system software | Manages computer hardware, files, memory, and applications |
| Google Chrome | Software | Application software | Used to browse websites |
| LibreOffice Writer | Software | Application software | Used to create and edit documents |
| Microsoft Defender Antivirus | Software | Utility software | Helps protect the computer from malware |
| Disk Cleanup / Storage cleanup tool | Software | Utility software | Helps remove unnecessary files and free storage space |

## Key concepts to remember

- **Input:** Data entered into a computer.
- **Processing:** The CPU works on the data by following instructions.
- **Output:** The information produced by the computer.
- **Storage:** Data and results saved for future use.
- **Hardware:** Physical computer components.
- **Software:** Programs and instructions that run on hardware.
