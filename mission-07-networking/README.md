# Mission 7 — Networking

Explore basic network concepts and how devices communicate.

## Topics to cover

- [ ] Explain what a computer network is.
- [ ] Distinguish LAN and WAN.
- [ ] Describe IP addresses and domain names.
- [ ] Explain the roles of DNS, routers, and switches.
- [ ] Describe the basic purpose of HTTP and HTTPS.
- [ ] Understand why network privacy and security matter.

## Notes and observations

Use safe, public examples only. Do not publish private IP addresses, Wi-Fi passwords, or details about a private network.
